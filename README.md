# 🎬 Netflix Power BI Dashboard

An interactive **Power BI dashboard** built to explore and analyze Amazon Prime Video movies and TV shows. The dashboard provides insights into content types, genres, ratings, countries, and release trends.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development & visualization
- **Power Query** – Data cleaning & transformation

## 📊 Key Analysis

- 🎥 Movies vs. TV Shows
- 🎭 Popular genres and content categories
- ⭐ Content ratings distribution
- 🌍 Country-wise content distribution
- 📅 Content release trends over the years

## 🎯 Project Objective

The goal of this project is to transform Netflix content data into an interactive dashboard and identify meaningful patterns and trends through data visualization.
